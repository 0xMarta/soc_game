# SOC Defense – Cyber Base8

Prototyp gry o tematyce **cyberbezpieczeństwa** napisanej w **HTML i JavaScript**.

Gracz broni infrastruktury cyfrowej (SOC – Security Operations Center) przed nadchodzącymi zagrożeniami cybernetycznymi.  
Repozytorium zawiera **grywalny prototyp** gry działającej w przeglądarce.

## Funkcje

- gra działająca w przeglądarce
- napisana w **HTML + JavaScript**
- nie wymaga dodatkowych bibliotek
- grywalny prototyp
- motyw cyberbezpieczeństwa

## Rozgrywka

Celem gry jest **obrona infrastruktury SOC przed cyberatakami**.  
Przeciwnicy reprezentują różne zagrożenia cyfrowe, które zbliżają się do bazy.

Zadaniem gracza jest reagowanie i zatrzymanie ataków zanim dotrą do głównej infrastruktury systemu.

## Jak uruchomić

1. Sklonuj repozytorium:

```bash
git clone https://github.com/0xMarta/soc_game.git
```

2. Otwórz plik gry w przeglądarce:

```
soc_defense_cyber_base8_grywalny_prototyp_html_js.html
```

Można go uruchomić po prostu **klikając dwa razy plik** lub otwierając go w dowolnej nowoczesnej przeglądarce.
